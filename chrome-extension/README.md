# FutureCare Not Done Sync — Chrome Extension

إضافة من مرحلتين لمتابعة حالات الطبيب التي تحقق `DRP > 0` و`DRD = 0`.

## التثبيت

1. افتح `chrome://extensions`.
2. فعّل **Developer mode**.
3. اختر **Load unpacked** وحدد مجلد `chrome-extension`.
4. افتح إعدادات الإضافة وأدخل Google OAuth Client ID.
5. أضف Redirect URI المعروض في الإعدادات إلى Google Cloud OAuth Client.
6. فعّل Google Drive API وGoogle Sheets API في مشروع Google Cloud.

## المرحلة الأولى

1. افتح الداشبورد وحمّل ملف الأداء.
2. افتح `Not Done — DRD=0` وطبّق الفلاتر المطلوبة. ستظهر لوحة الإضافة داخل التبويب نفسه.
3. من اللوحة داخل الصفحة اختر **التقاط الحالات**.
4. اختر **إنشاء روابط الأطباء** لإنشاء Google Sheet مستقل لكل طبيب.
5. أرسل رابط الطبيب له لإدخال السبب من القائمة فقط.

## المرحلة الثانية

1. سجّل الدخول إلى iCare وافتح:
   `https://icare.com.sa/performance-follow-up/nursing-or-pt`
2. اختر الشهر والمدينة والقسم GP واضغط Load.
3. من الإضافة اختر **مراجعة الأسباب**.
4. راجع عدد الحالات الجاهزة والمتوقفة.
5. اختر **تطبيق الأسباب داخل iCare**؛ ستبحث الإضافة بالـPTID في جميع صفحات النتائج، وتختار السبب في قسم GP فقط، ثم تضغط حفظ لكل حالة مطابقة.

## ضوابط الأمان

- المطابقة تتم بـ PTID، ولا تُطبّق الحالة إذا كان PTID غير ظاهر أو مكرر.
- القيمة يجب أن تطابق خيارًا موجودًا في قائمة iCare، وإلا تتوقف الحالة للمراجعة.
- قبل الحفظ تعرض الإضافة مرحلة مراجعة وعدد الحالات الجاهزة والمتوقفة، ثم تطلب تأكيدًا صريحًا قبل الضغط على أزرار الحفظ داخل iCare.
- خيار الرابط العام القابل للتحرير يعرض بيانات مرضى لمن يملك الرابط. استخدم مشاركة بريد الطبيب بدل الرابط العام متى أمكن.
